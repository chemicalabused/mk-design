# Materiały referencyjne

Wrzuć tutaj wszystko z istniejącego projektu: screeny, logo, fonty, teksty,
eksporty z Figmy, stary kod HTML/CSS, linki do live strony.

Podkatalogi są opcjonalne, ale ułatwiają analizę:

- `brand/` – logo, kolory, fonty
- `screens/` – zrzuty ekranu obecnej strony lub makiet
- `portfolio/` – prace do pokazania (obrazy, opisy)
- `copy/` – teksty: bio, opisy usług, kontakt
